DEEPSEEK · 历史异常已审计

排队超时，不等于模型切换

历史一次 HTTP 200 error-only 响应表示 900 秒排队超时，model / usage 均缺失；程序先检查模型字段而误报身份变化，不能据此认定实际模型切换。另有一次 HTTP 200 空 completion。

旧失败与部分结果保留。受审恢复已执行；不重跑旧格、不补零、不修摘要。单格 watchdog 超时与服务排队超时分别记录。

为什么不能把这里的收益称为连续实盘？

这是回溯研究，每个年度账户独立重置。年度累计收益可做描述均值，但不能复利拼接为跨年 CAGR；当前测试样本也不能称为未接触的确认样本。ALL 是数据覆盖的沪深股票样本，不是完整全 A；历史行业分类修订的可追溯保证尚未验证。

07 / WHAT THE EVIDENCE SAYS

摘要未显示稳定增益，下一步先改善可靠性

现在可以说

当前完整配对反映特定年份、股票池和成功执行条件下的差异。预测信息与净收益可能背离，应分别报告；额外摘要资源也应计入。

仍然不能说

不能依据条件有效均值宣布可实盘 alpha，也不能用部分行业的改善证明普遍有效。DeepSeek 的 516 格均已有终态；GLM 的 303 格永久排除。原始控制器的 BLOCKED_WITH_UNSTARTED 指这些被排除的 GLM 格，不代表仍有 DeepSeek 格等待执行。仍须同时审视失败率、年份覆盖、交易成本与有效样本选择偏差。

NEXT / V2 RESEARCH PLAN

下一步，把优化变成可验证的假设

独立 V2 建议 · 尚未执行
01

先提高摘要可靠性

将证据计算、结构化决策和展示文字分开。在新协议中预先定义摘要格式校验与降级行为；保留失败原文和使用状态。先做离线异常回放，再验证端到端完成率。

02

让 Memory 的作用可追踪

证据卡绑定候选、父候选、训练截止和具体修改，记录“被召回—被使用—训练内结果”。比较有效新增因子、去冗余后的相关簇和每千 token 的搜索产出，再检查经济表现。

03

小规模对照后再扩展

先比较原始训练证据、确定性证据卡、模型摘要三个处理，预先固定资源上限和成组样本；保留强基线，观察净组合贡献、成本及年份稳定性。已查看的年份仅作开发分析。

这些是后续研究方案，不是已获得的收益改善。V1 的科学源码、阈值和终态保留；不补跑旧失败、部分完成或空组合，也不据此选择最有利的测试期参数。
