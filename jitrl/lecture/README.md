# JitRL 方法讲义

按论文 Section 4 和用户提供的详细解释组织。每页的设计动机、概念解释、具体计算和结果含义均直接显示在正文中。

提供两种视图：连续阅读适合学习和查阅，逐页演示支持方向键翻页。网页与图片版 PPT 使用相同的页面内容和排版。演示画布为 1600 × 900，阅读模式可在手机上重新排版。

数据口径：案例为独立教学构造，γ=0.5、β=1、ε=10⁻⁸，旧邻域回报为 −2、0、4、6、2。奖励尺度不是论文 WebArena 的 −3 至 3 配置。这组计算也不同于上层旧版交互实验。
