把预测能力与经济价值分开

01

先看 IC / ICIR

IC 看整个股票截面的收益排序；ICIR 看平均 IC 相对于其波动的大小。它们描述冻结组合信号，不是所有生成候选的平均质量。

02

再看收益 / 风险 / 换手

最高 20% 股票等权多头、每 5 日换仓、买卖每边 10 bps。正 IC 不保证该组合跑赢基准，也不保证绝对盈利。

03

最后看配对和重复

同模型、同池、同年、同重复编号比较处理增量。只有三次重复，且共用一年市场，均值优势不能代替稳定性。

M3−M2 的收益增量拆解

单位 pp。成本情景影响差 = Δ10bps净超额 − Δ零成本超额，包含成本改变账户路径的影响，不能称为逐笔纯手续费归因。

GLM / C39

净收益改善，毛收益却更差

零成本超额增量 −1.215 pp，成本情景影响差 +1.372 pp，净增量仅 +0.157 pp；日双边换手减少约 6.21 pp。改善与交易负担减轻一致，不能解释为毛收益更强。

Flash / C39

IC 改善，没有转成净收益

M3−M2 的 IC 增加 0.01172，净收益却减少约 0.084 pp。需要补分组收益、顶部持仓、暴露与成交归因，不能只依据全截面 IC 解释收益。

尚未验证可实盘：每边 10 bps 是研究情景；分数股、历史涨跌停、ST、逐期真实税费、冲击和容量未完整建模。净收益优于基准也不等于风险因子回归后的 alpha。

−0.93+6.09−1.78

Flash / C35：摘要增量仍分散

−1.88+11.02+9.30

M3−M2 三次净年化差，平均 +6.15 pp。M3 相对 M0 三次均改善，但摘要相对 M2 的稳定增益仍需确认。

细线=每次重复；粗线=每个日期的重复中位数，仅用于描述分布，不是一条可交易账户。相对净值大于 1 表示跑赢基准，不能解释成绝对盈利。每条线对应实际完成的冻结组合。

序列依赖

238 日，并非 238 次独立试验

每日滚动预测未来 5 日收益，标签相互重叠；96 单元日 IC 一阶自相关中位数约 0.776。没有把 ICIR 乘 √252，或用朴素每日 t 检验包装显著性。

机制反证

相同证据加摘要，尚未证明有效

GLM 同 checkpoint 的三对机制检验，下一批候选平均验证 IC 由 0.04123 降为 0.03863，差 −0.00261。全流程局部改善不能替代摘要内容机制的证据。

冻结单因子的训练 / 验证 / 测试诊断

519 条冻结记录、451 个不同公式文本，464 条测试 IC 为正。下表只描述已入选因子；验证期用于选优，组间股票池与因子数量不同，不能用于直接估计 Memory 效应。

测试均值均低于验证均值，与筛选效应、市场变化或信号衰减均相容，当前无法区分原因；公式文本不同也不代表信息独立。

一轮具体如何使用训练集？

模型提出公式，本地程序在“股票 × 交易日”的行情面板上计算因子值。每天跨股票计算分数与未来 5 日收益的 Spearman 相关，再汇总训练期 IC / ICIR。先对固定 100 只股票子样本快筛，通过者再用完整股票池训练面板评分；合格、低冗余的因子入库，满足更严格条件的新因子可以替换旧因子。

十轮复用同一训练期，改变的是候选公式、因子库和允许使用的经验，不是逐月推进，也不更新大模型权重。历史数据可用于长窗口预热，但预热期不参与目标评分；跨训练边界的收益标签剔除。

GLM / ALL / M0 / 第一次重复：十轮末库内数量依次为 4、5、5、5、5、7、8、10、11、11；验证后冻结 9 个因子。不是每轮 20 个都能留下。

指标词典与统计分母

Rank IC：冻结组合信号与 open[t+6] / open[t+1] − 1 的每日截面秩相关，再按日取均值。

ICIR：每日 IC 均值 / 样本标准差，未年化。不是持仓组合的主动收益 IR。

净年化 / 超额：按实际账户收益步数缩放到 252 交易日；超额为策略 CAGR 减同池基准 CAGR，不是风险调整 alpha。

Sharpe / 回撤：Sharpe 用日净收益均值 / 标准差 × √252，未扣独立无风险利率；回撤为账户净值相对历史峰值的最大跌幅。

换手 / 成本：日均买入加卖出名义金额 / 净值，属于双边换手；主情景买卖每边 10 bps。

n / 因子数：n 为成功重复次数。96 个完整单元共 19,200 候选槽位、19,143 个解析有效候选、519 条最终冻结因子记录；这些不是独立统计样本数。

08 / RESEARCH JUDGEMENT

值得继续研究，尚不足以宣布成功

当前判断

Memory 的价值取决于模型与股票池，预测和收益必须分别判断。

完整96格显示：M3 相对 M2 在5/8个层面平均 IC 改善、5/8个层面净收益改善；相对 M0 则仅2/8个层面 IC 改善、6/8个层面净收益改善。Flash 全市场有预测和经济表现同时改善的线索，专用设备有较强超额；电子通信池则提示增加 Memory 可能损害表现。单年结果仍不足以支持普遍增益或可实盘 alpha。

已经得到的证据

  • M3−M2：24对中14对 IC 改善、16对净收益改善；Flash 全市场两项指标均3/3改善。
  • M3−M0：24对中8对 IC 改善、16对净收益改善；Flash 电子通信池两项均0/3改善。
  • 每模型48格，零成本平均超额为正，10 bps 主情景均转负；全部单元绝对净年化为负。

仍然缺少的证据

  • 分位组收益、顶部收益来源、不同持有期 IC、标准因子条件增量与风险暴露。
  • 连续多年完整四组与更多生成重复；独立封存、未参与参数选择的最终评价阶段。
  • 历史行业快照修订不可变性、存续与成交约束审计、现实冲击与容量。
01

固定共同执行与评价协议

统一输出格式验证、有限重试与资源上限；在各组使用相同的执行规则。完成行业快照来源与逐年覆盖审计，区分每次尝试成功率与最终可评价结果。

02

补齐从 IC 到收益的归因

同一冻结因子集输出分组收益、顶部持仓表现、规模/流动性暴露、换手与成本归因。不要用已经看过的测试期反复选最有利参数。

03

成组执行多年 M0–M3

按年份×股票池运行完整四组，保存所有重复及失败。年度独立 Memory 与跨年继承另行设组；固定候选预算与固定总资源的效率问题分开研究。

04

预设能否接受或否定假设的标准

先写主要对比、最小经济增量、重复数与依赖调整方案。区分生成随机性和市场时间依赖，保留封存确认阶段，并补充未来纸面交易。

方法可比性说明

本表汇总96个可评价单元，模型、数据划分、因子准入、验证筛选和回测口径一致；其中11个单元采用了最多3次的网络／摘要格式重试，摘要重试可附格式纠错要求，原生解析规则未放宽。该执行规则与额外推理资源并非所有单元完全一致，因此跨组差异作为描述性结果，不作严格因果解释；完整覆盖不代表首次执行成功率100%。所有原始尝试均保留。
